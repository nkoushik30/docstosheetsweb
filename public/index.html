Microsoft Tools

Microsoft Word — Key Tools & Features

  • Home Tab: Font styling, Paragraph alignment, Bullets & Numbering
  • Insert Tab: Images, tables, links, headers, footers
  • Design Tab: Themes, Document formatting, Watermarks
  • Layout Tab: Page margins, orientation, spacing
  • References Tab: Table of contents, citations, bibliography
  • Review Tab: Spelling & grammar, comments, track changes
  • View Tab: Read mode, print layout, zoom controls
📊

Microsoft Excel — Key Tools & Features

  • Home Tab: Clipboard, Font, Alignment, Number, Conditional formatting
  • Insert Tab: Tables, PivotTables, Charts, Sparklines, Filters
  • Page Layout: Themes, Page setup, Scale to fit, Sheet options
  • Formulas Tab: Function Library, Defined Names, Formula Auditing
  • Data Tab: Sort & Filter, Validation, Remove duplicates, Forecast
  • Review Tab: Spelling, Accessibility, Comments, Protect Sheet
  • View Tab: Workbook Views, Zoom, Window arrangement, Macros

Microsoft Teams — Key Tools & Features

  • Chat Tab: Instant messaging, file sharing, emoji, GIFs
  • Teams Tab: Create/join teams, collaborate on channels
  • Calendar Tab: Schedule meetings, join video calls
  • Calls Tab: Voice/video calls, voicemail, contacts
  • Files Tab: Recent docs, shared files, OneDrive access
  • Apps Tab: Integrate Planner, Forms, Power BI

  • /call /files /goto — Command shortcuts
  • Settings: Notifications, themes, privacy options

Visual Studio Code — Key Shortcuts

  • Ctrl+P — Quick open files by name
  • Ctrl+Shift+P — Open Command Palette
  • Ctrl+` — Toggle integrated terminal
  • Ctrl+B — Toggle sidebar visibility
  • Ctrl+Shift+E — Show Explorer
  • Ctrl+Shift+F — Find in files
  • Ctrl+/ — Toggle line comment
  • Alt+Up/Down — Move line up/down
  • Ctrl+Space — Trigger IntelliSense
  • F12 — Go to definition
  • Shift+Alt+F — Format document
  • Ctrl+Shift+M — Show Problems panel
📈

Microsoft Power BI — Key Shortcuts

  • Ctrl+N — Create a new report
  • Ctrl+O — Open an existing report
  • Ctrl+S — Save current report
  • Ctrl+Z — Undo last action
  • Ctrl+Y — Redo last action
  • Ctrl+C/V — Copy and paste visuals
  • Ctrl+G — Group selected visuals
  • Ctrl+Shift+G — Ungroup visuals
  • Ctrl+D — Duplicate selected visual
  • Ctrl+Arrows — Nudge visuals on canvas

  • Notebooks/Sections/Pages: Organize hierarchically
  • Ink & Drawing: Write or sketch with stylus/touch

About DocsToSheets

DocsToSheets is an educational platform designed to help beginners and students easily learn the basic tools of Microsoft Word, Excel, and popular Google services. Whether you're preparing documents, managing data, or building apps, DocsToSheets breaks each feature into simple, approachable guides.

We know that many users struggle with formatting documents, writing formulas, or navigating developer tools. That's why we've built a friendly, no-jargon space with:

  • Easy-to-remember keyboard shortcuts
  • Clear explanations of Word, Excel, and Teams tools
  • Practical guides for Firebase, DevTools, Android Studio, and more
  • Simplified layouts for fast, confident learning

Whether you're a school student, college learner, or a professional building new skills — DocsToSheets gives you the foundation to work confidently with both Microsoft and Google tools.
